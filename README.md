# AiDi Hub

Skills and tools for product design work, by Aigul Gambarova (AiDi).

## Skills

| Skill | What it does | Security |
|---|---|---|
| [design-hypothesis](skills/design-hypothesis/SKILL.md) | Turns a vague task into testable product and UX hypotheses with metrics, pass/fail criteria, a cheap validation plan and ICE/RICE prioritization. | [![Security grade from Skills Directory](https://www.skillsdirectory.com/api/skills/aigammma-design-hypothesis/badge)](https://www.skillsdirectory.com/skills/aigammma-design-hypothesis) |

## Install

All skills:

```bash
npx skills add AiGammma/AiDi-Hub
```

One skill:

```bash
npx skills add AiGammma/AiDi-Hub --skill design-hypothesis
```

Works with Claude Code and other agents that support `SKILL.md`.
