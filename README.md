# AiDi Skills

Agent skills for product designers, by Aigul Gambarova.

## Skills

| Skill | What it does |
|---|---|
| [design-hypothesis](skills/design-hypothesis/SKILL.md) | Turns a vague task into testable product and UX hypotheses with metrics, pass/fail criteria, a cheap validation plan and ICE/RICE prioritization. |

## Install

```bash
npx skills add AiGammma/AiDi
```

Works with Claude Code and other agents that support `SKILL.md`.
