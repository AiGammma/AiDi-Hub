# cinebot — персональный бот-подборщик фильмов и сериалов

Telegram-бот, который по твоим оценкам и вишлисту из Кинопоиска и списку любимых режиссёров подбирает, что смотреть. Отдельный режим `/english` выбирает то, на чём удобно тренировать **американский английский**.

Архитектура сразу рассчитана на несколько пользователей, тарифы и (по согласию) выгрузку обезличенных вкусов. Всё это заложено, но **выключено**: сейчас бот работает как личный и без ограничений. Подробности в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Что нужно для запуска

| Что | Где взять | Зачем |
|---|---|---|
| Токен бота | [@BotFather](https://t.me/BotFather) → `/newbot` | Telegram |
| Ключ TMDB | themoviedb.org → Settings → API (бесплатно) | Данные о фильмах: режиссёры, жанры, страны, похожие |
| Ключ Anthropic (необязательно) | console.anthropic.com | Персональные объяснения и словарь для `/english`. Без него бот работает на правилах |

## Запуск

```bash
cd apps/cinema-bot
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env        # впиши токены
python -m cinebot
```

Тесты: `pytest`.

## Как пользоваться

1. `/import` и пришли CSV/TXT с оценками из Кинопоиска (колонки `Название; Год; Моя оценка`, остальные необязательны).
2. `/wishlist` — вишлист файлом или текстом, по фильму на строку: `Начало (2010)`.
3. `/directors Кристофер Нолан, Дени Вильнёв`.
4. `/pick` — подборка под вкус, `/english` — подборка для практики английского.
5. Под каждой рекомендацией кнопки 👍 👎 ✅ 🔖: это обратная связь, она влияет на следующие подборки.

Остальное: `/profile`, `/plan`, `/privacy`, `/my_data`, `/delete_me`.

## Важные оговорки

* **Выгрузка из Кинопоиска.** Официального API для личных оценок нет. Парсер терпимый к кодировке, разделителю и названиям колонок (русским и английским), но я не видела реального файла вашего экспортёра. Если бот скажет, что не нашёл колонку с названием, пришли первые строки файла, и я подстрою.
* **Доступность TMDB из России** не проверена. Если API недоступен, разверни бота на зарубежном сервере или поменяй `CINEBOT_TMDB_BASE_URL`.
* **Бот не запускался против живых Telegram, TMDB и Claude**: в разработке не было ключей. Логика покрыта тестами с фейковым TMDB и заглушкой Claude. Первый реальный прогон на твоих данных стоит сделать самой и посмотреть, адекватны ли подборки.
* Словарь в режиме `/english` — типичная лексика жанра и сеттинга, а не цитаты из фильма. Бот так и пишет.
